# 🧠 PLAN BEFORE EXECUTE RULES

## 1. Analisis Sebelum Bertindak
Setiap kali user meminta fitur baru, perombakan besar (seperti migrasi html2pdf ke react-pdf), atau perbaikan bug yang kompleks:
- JANGAN langsung men-generate kode (coding).
- Berhenti sejenak, dan tuliskan Rencana Eksekusi (Execution Plan) secara singkat berupa bullet points.

## 2. Persetujuan User
- Berikan rencana tersebut kepada user dan tanyakan: "Apakah rencana ini sudah sesuai, atau ada yang ingin disesuaikan?"
- Baru mulai menulis dan memodifikasi file setelah user memberikan persetujuan (approval) atas rencanamu.
